# Karachi Runner

A 2D endless runner set in Karachi. Pick one of three runners, run through real Karachi streets, jump and slide past rickshaws, buses and barriers, collect coins, biryani and chai, and chase a place on the Top 5 leaderboard saved in a file.

Built as the CS 1420 OOP course project under Sir Faisal Feroze, MAJU.

Project status: the skeleton, menu screen and the three playable characters are in place. Gameplay, obstacles, maps and the leaderboard are being added phase by phase. Screenshots: coming soon.

## Controls

- Enter: start on the menu
- Space, W or Up arrow: jump
- S or Down arrow: slide
- P: pause and resume
- Esc: back to menu
- Arrow keys and Enter: move and select in menus

## The 4 maps

1. Clifton and Sea View: the beach, Teen Talwar, Mohatta Palace, Dolmen towers and the big flag. The easy map.
2. Shahrah-e-Faisal: FTC Building, pedestrian bridges full of ad boards, Nursery furniture on the pavement, Star Gate at the airport end.
3. University Road: Karachi University Silver Jubilee Gate, NED, Expo Centre and Safari Park, with university point buses.
4. Saddar: KMC Market (Empress Market) and its clock tower, Zainab Market, Rainbow Centre and the narrow board covered streets. The hardest map.

## The 3 characters

- Mashhood Ali: the balanced all rounder. Standard speed, standard jump, 3 hearts, no special power.
- Shayan: the fastest, with the highest jump and 3 hearts, but his slide is very short.
- Aryan: the heavy one. Slowest speed and lowest jump, but 4 hearts, and his weight lets him smash road barriers and thelas without losing a heart. Buses and rickshaws still stop him.

## How to build (Visual Studio 2022)

You need Visual Studio 2022 with the Desktop development with C++ workload, which includes CMake.

1. Clone or download this repo.
2. Open the project folder in Visual Studio 2022 (File, Open, Folder).
3. Visual Studio reads CMakeLists.txt and configures the project. The first configure downloads SFML 3.1.0, so you need internet once.
4. Select the x64 configuration, then build and run.

SFML note: this project uses SFML 3.1.0, pinned in CMakeLists.txt. SFML 3 changed its API, so code copied from old SFML 2.6 tutorials will not compile here. Everything in this repo follows the SFML 3.1 API.

Font note: the menus need a font file at assets/fonts/main.ttf. Put any free font file there with that name. Without it the game still opens, but the menus show no text. See assets/README.txt for the art and sound rules of this project.

## OOP concepts in the code

Every concept comes from the CS 1420 course outline, and nothing outside the outline is used:

- Encapsulation with getters and setters in Player and Score
- Abstraction: GameObject and GameState are abstract classes with pure virtual functions
- Inheritance: single, multilevel, hierarchical and multiple, including the diamond solved with virtual inheritance
- Runtime polymorphism: the game loop calls update and draw through base class pointers
- Static members, inline functions and arrays of objects
- Friend operator for printing a Score, function and operator overloading
- Custom exception class for file loading, caught in main
- dynamic_cast for the Aryan smash rule, static_cast for score values
- File handling with full CRUD for the Top 5 leaderboard, and a Mapper class that turns a Score into one text line and back
- Composition, aggregation and association between the classes
