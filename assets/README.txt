Karachi Runner assets folder

textures/  Character, obstacle and map art will live here.
           All art for this game is original hand drawn pixel art,
           made by us in free tools like Piskel and LibreSprite.
           No AI generated art and no copied images are used.

audio/     Sound effects live here. The current effects
           (jump.wav, coin.wav, hit.wav, click.wav, smash.wav,
           gameover.wav) were generated by us with
           tools/make_sounds.py: short original sine sweeps and
           noise bursts, written by a script we wrote. They are
           our own generated sounds, so there are no third party
           rights on them at all.
           Any sound added later will be CC0 (public domain),
           generated by us, or our own recorded voices.
           No copyrighted music or reel audio is used.

fonts/     The game looks for a font file named main.ttf here.
           Put any free font file in this folder and rename it to
           main.ttf. If the font is missing the game still opens,
           but the menu screens show no text.
           An optional second file, urdu.ttf, enables the Urdu
           dedication lines (the Saddar wall panel and the
           credits screen). Use a free Urdu font, for example
           Noto Nastaliq Urdu from Google Fonts. If urdu.ttf is
           missing, those lines are skipped and nothing breaks.
